# VØID · ручная проверка на реальных платформах (этап 8)

## Что уже проверено автоматически, а что нет

### Проверено автоматически

Все проверки — в облачной среде, без реальных устройств.

| Что | Чем | Итог |
|---|---|---|
| Chromium 153 без окна, ПК 1280×760 | variants8, offline8, accept8 (стенды, K, fps6 с виртуальной частотой) | см. отчёт этапа |
| Эмуляция телефона Pixel 7: касания, масштаб, user-agent | offline8 (режим «телефон») | меню → бой, 0 ошибок |
| file://, локальный HTTP, полностью без сети | offline8 | запросы = 1.5.35 |

### Не проверено (в этой среде нет устройств)

- Safari на iPhone и iPad, в том числе в режиме энергосбережения: там браузер сам режет частоту кадров до 30.
- Chrome на реальном Android.
- Firefox, Safari на macOS.
- Мониторы 120 и 144 Гц.
- Настоящие касания, геймпад, звук через динамики.
- Облачное сохранение в настоящем хранилище артефакта.
- Telegram Web App, будущая обёртка Electron, публичный хостинг (ТЗ 12.6).

| Платформа | Статус |
|---|---|
| iOS Safari (iPhone, iPad) | не проверено |
| Android Chrome | не проверено |
| Firefox, Safari macOS, Edge | не проверено |
| Мониторы 120 / 144 Гц | не проверено (только виртуальная частота в fps6) |
| Telegram Web App | не проверено |
| Electron | не проверено (обёртки ещё нет) |
| Публичный хостинг (https) | не проверено; локальный HTTP — PASS (offline8) |
| Chromium ПК, file:// и HTTP, без сети | PASS (offline8) |
| Эмуляция Pixel 7 | PASS (offline8) — это эмуляция, а не устройство |

Итоговый HTML этапа 8 побайтно равен 1.5.35. Поэтому всё, что проверялось на устройствах для 1.5.35, к нему применимо без изменений. Ручная проверка нужна только для версий, у которых SHA отличается от `b936a549…`.

## Что подготовить

1. Файл `dist/void.html` и его SHA-256 (`sha256sum dist/void.html` или `certutil -hashfile void.html SHA256`). Запишите SHA в протокол: проверяется именно этот файл.
2. Отдельный профиль браузера или приватное окно, чтобы не задеть реальные сохранения игрока. **Не открывать на устройстве, где лежит настоящий прогресс, без резервного кода сохранения** (меню → сохранение → код).

## Чек-лист для каждой платформы

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Открыть файл (file://) или по ссылке | Меню, музыка после первого касания или через 0,5 с, версия «1.5.35 α» |
| 2 | Новый полёт → миссия 01 | Бой, полосы корпуса и энергии, стрельба |
| 3 | 2 минуты боя | Нет подвисаний и сообщений об ошибке; строка «КАДРЫ» (ПК) показывает предел |
| 4 | Пауза → настройки → предел кадров 30 / 60 / без ограничения | Переключается; на 120/144 Гц «без ограничения» плавнее |
| 5 | Карта (M или кнопка), возврат | Карта открывается и закрывается |
| 6 | Выйти в мир, ангар, Арсенал | Экраны открываются |
| 7 | Закрыть вкладку, открыть снова | Прогресс на месте |
| 8 | Код сохранения: экспорт и импорт в приватном окне | Прогресс переносится |
| 9 | Режим полёта (без сети), перезагрузка | Игра работает; шрифт может стать системным — это ожидаемо (см. ниже) |
| 10 | Телефон: поворот экрана, сворачивание и возврат | Пауза при сворачивании, интерфейс по размеру |
| 11 | Телефон: стик, рывок свайпом, импульс | Отклик без залипания |
| 12 | iPhone с энергосбережением | Игра идёт (около 30 кадров), без ускорения или замедления симуляции |

## Протокол

Для каждой платформы запишите:

- устройство;
- ОС и браузер с версией;
- SHA файла;
- результат по каждому номеру чек-листа: PASS / FAIL / не проверено, с комментарием.

Если пункт не проверялся, так и пишется: «не проверено». Не проверенное не выдаётся за пройденное.

## Известное поведение (не дефект этапа 8)

- **Веб-шрифты Google Fonts.** Игра запрашивает их (Unbounded, Exo 2, JetBrains Mono). Без сети используются системные шрифты, и игра работает. Так было и в 1.5.35: offline8 сверяет список запросов с эталоном.
- **Без CINE.** Сборка без группы cine (`build8 build --without cine`) в живом цикле останавливается на паузе: cut.cine.live, см. `docs/FOLLOWUP_cut_cine_live.md`. Опубликованной игры это не касается.
