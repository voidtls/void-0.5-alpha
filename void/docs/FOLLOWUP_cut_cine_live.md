# Отдельная задача после этапа 8: исправить cut.cine.live

## Дефект

- **С какой версии:** 1.5.14 (ARCH·74, A-21). Зарегистрирован в `build/invariants.json` → `known.cut.cine.live`.
- **Где:** строка скрипта 152 = `src/js/loop/0040-arch72-76-clock-step-interp.js:28`, функция `step74`:
  ```js
  if(ARCH.c66s){try{c66Tick(STEP74);}catch(e){c66Fail(e);}}/* ARCH·74 A-21 */}
  ```
- **Причина:** `c66Tick` и `c66Fail` объявлены только в вырезаемом блоке CINE·PROTO (`src/js/opt/cine/1210-cine-proto-151.js`). В сборке без группы cine (`build8 build --without cine`) каждый шаг игры бросает `ReferenceError: c66Fail is not defined`. Защита ARCH·69 через ~0,5 с ставит игру на паузу.
- **Чего дефект не затрагивает:** полную сборку (опубликованная игра) и сборку без bg.
- **Подтверждение:**
  - `variants8` — без cine и без cine+bg: 30 ошибок, только эти, только в `step74`;
  - `build8 check` — пункт dangle, KNOWN;
  - тот же стек показан в demo8, задача 3.

## Предлагаемое исправление (проверено только на копии)

Строка скрипта 178 = `src/js/loop/0040-arch72-76-clock-step-interp.js:54`:

```js
ARCH.c66s=!ARCH.off['A-21']&&!ARCH.off['A-20']&&!ARCH.off['A-19'];
```
→
```js
ARCH.c66s=!ARCH.off['A-21']&&!ARCH.off['A-20']&&!ARCH.off['A-19']&&typeof c66Tick==='function';
```

### Почему здесь, а не в `step74`

Анализ по индексу (`build8 where`):

- **`ARCH.c66s` читается в трёх местах:**
  - `step74` (loop:28);
  - `c66Clk` (loop:55);
  - внутри cine.
- **`c66Clk` используется только в cine:** 7 мест в `opt/cine`.
- **В полной сборке поведение не меняется.** `c66Tick` объявлен как `function` и поднимается при загрузке, поэтому на строке 178 `typeof` уже равен `'function'`: значение `ARCH.c66s` то же, игра та же.
- **В сборке без cine флаг становится `false`,** и `step74` больше не вызывает отсутствующие функции. Код, которому нужен такт C66, вырезан вместе с cine.

### Другой вариант

Защита прямо в месте вызова (loop:28: `if(ARCH.c66s&&typeof c66Tick==='function')`). Тоже корректен, но проверяет условие на каждом шаге. Решает владелец.
